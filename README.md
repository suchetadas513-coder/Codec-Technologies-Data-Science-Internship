# Codec Technologies Data Science Internship Projects

This repository contains the official project submissions completed during my Data Science internship at Codec Technologies.

## Project 1: Customer Churn Prediction
* Objective:Predict telecom customer churn using demographic and account features.
* Dataset: Telco Customer Churn (7,032 records processed).
* Best Model: Logistic Regression (Accuracy: **80.38%**, Recall: **57.22%**, ROC-AUC: **0.8359**).
* Key Finding: Logistic Regression outperformed Random Forest, proving to be better at catching at-risk customers (higher Recall) to maximize corporate retention strategies.

## Project 2: Credit Risk Modeling
* Objective: Classify financial loan applicants into Good or Bad credit risks.
* Dataset: UCI Statlog German Credit Data (1,000 records).
* Model Performance: Logistic Regression (Accuracy: **78.00%**, Recall: **53.33%**, ROC-AUC: **0.8040**).
* Key Finding: The model revealed that an overdrawn checking account status (< 0 DM) and education-focused loans are the strongest risk indicators for default, while a clean repayment track record on previous accounts acts as the highest safety indicator.
